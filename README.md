# 💼 Job Portal

A full-stack Job Portal web application built with **Java**, **Spring Boot**, **Spring Security**, **Thymeleaf**, **JPA (Hibernate)**, and **MySQL**. Connects job seekers with employers through a secure platform for job posting, applications, and user management.

## 📖 Overview

The Job Portal simplifies recruitment by letting employers post job openings and job seekers search and apply online. Built with Spring Boot for the backend, Spring Security for authentication, and MySQL for storage.

## 🚀 Installation

**1. Clone the repository**
```bash
git clone https://github.com/Nesara29/prajju.git
cd prajju
```

**2. Configure MySQL**

Create a database, then update `src/main/resources/application.properties` with your credentials.

**3. Build the project**
```bash
mvn clean install
```

**4. Run the application**
```bash
mvn spring-boot:run
```

**5. Open your browser**
```
http://localhost:8080
```
